What the pipeline does

  1. Field of view. Finds the lit scope circle. Nothing outside it is touched.
  2. Glare. Flags bright, colourless highlights and fills them from surrounding tissue (normalized convolution, constant run time).
  3. Smoke. Dark-channel dehazing adapted to tissue: a neutral airlight and a tissue floor keep clear frames unchanged, with temporal smoothing against flicker.
  4. Contrast. CLAHE on luminance, applied as one gain per pixel so tissue hue does not shift.

How it is verified

Each requirement in the SRS has an automated test. Synthetic footage is rendered with known ground truth, so smoke removal is scored by colour error (CIEDE2000), PSNR and SSIM against the clean frame, not by eye.

Latency here is measured inside the C++ pipeline on a 4-core cloud VM. Decode, encode and display are excluded.
